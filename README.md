# Qraviq — Free QR Code Generator

A professional, privacy-first QR code generator built with **React + Vite**. Create
high-resolution QR codes, customize their colors and download them as PNG or SVG — all in
the browser.

## Features

- **Instant generation** — the QR code updates live as you type.
- **Custom colors** — curated presets or your own foreground/background colors.
- **High-resolution export** — PNG up to 1000x1000px or a scalable SVG.
- **Privacy first** — everything runs 100% in the browser; nothing is uploaded.
- **No signup** — free, unlimited and watermark-free.

- React 18 + React Router
- Vite

- Framer Motion

## Getting Started

```bash
npm install
npm run dev      # start the dev server
npm run build    # production build into dist/
npm run preview  # preview the production build
npm run lint     # run ESLint
```
